# Cinematic Title — Owlbear Rodeo Extension

Небольшой аддон для **Owlbear Rodeo**, который позволяет выводить на экран стилизованные кинематографичные титры при переходе между локациями.

Сейчас доступен один стиль:

* чёрно-белая высококонтрастная стилизация;
* красные и токсично-жёлтые акценты;
* затемнение сцены;
* крупный центральный заголовок;
* дополнительная строка текста;
* автоматическое скрытие через заданное время;
* ручная кнопка скрытия;
* текст автоматически переводится в ВЕРХНИЙ РЕГИСТР;
* попытка автоматически определить название текущей карты/сцены.

## Установка

В Owlbear Rodeo открой:

**Extensions → Add Extension**

И вставь ссылку:

```text
https://cinematic-title.altraboxel.workers.dev/manifest.json
```

После этого аддон появится в списке расширений комнаты.

## Использование

1. Открой панель **Cinematic Title**.
2. Введи название локации или оставь автоматически найденное.
3. При необходимости добавь вторую строку.
4. Выбери длительность показа и степень затемнения.
5. Нажми **ПОКАЗАТЬ ВСЕМ**.

Титр одновременно появится у всех игроков в комнате.

Кнопка **СКРЫТЬ** позволяет убрать заставку вручную.

## Примечание

Автоматическое определение имени сцены зависит от доступных данных Owlbear Rodeo. Если название определить не удалось или оно определилось неправильно, его всегда можно ввести вручную.
