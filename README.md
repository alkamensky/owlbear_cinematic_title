# Cinematic Location Titles for Owlbear Rodeo

Статический аддон для показа кинематографичных титров локаций всем участникам комнаты Owlbear Rodeo.

## Что умеет v1.1

- Поле заголовка по умолчанию пустое.
- Аддон пытается автоматически подставить название текущей сцены.
- Поскольку публичный Owlbear SDK не отдаёт системное имя открытой сцены отдельным методом, используется best-effort:
  1. проверка подходящего имени в metadata сцены;
  2. если его нет — имя крупнейшего изображения на слое `MAP` как вероятной основной карты.
- Автоподстановку всегда можно заменить вручную.
- Ручной текст не перезаписывается при смене сцены; автоматически меняется только пустое поле или предыдущая автоподстановка.
- Заголовок и подзаголовок всегда преобразуются в ВЕРХНИЙ РЕГИСТР.
- GM вводит название локации и необязательный подзаголовок.
- Одной кнопкой титр показывается всем подключённым участникам.
- Сцена временно затемняется.
- На поддерживаемых клиентах включается локальный GPU post-process: высокий контраст, почти полный монохром, сохранение глубоких красных и грязно-жёлтых акцентов.
- Через заданное время эффект автоматически исчезает.
- Кнопка `СКРЫТЬ` немедленно убирает заставку у всех.
- Звука в этой версии нет.

## Файлы

- `manifest.json` — манифест Owlbear Rodeo.
- `index.html`, `main.js`, `style.css` — GM-панель и автоподстановка названия.
- `background.html`, `background.js` — синхронизация и post-process.
- `overlay.html`, `overlay.js`, `overlay.css` — полноэкранная заставка.
- `icon.svg` — иконка расширения.
- `_headers` — CORS-заголовки для Cloudflare Static Assets / Pages.

## Установка

Разместите содержимое репозитория как статические файлы и добавьте в Owlbear Rodeo ссылку вида:

`https://YOUR-DOMAIN/manifest.json`

Node.js и сборка не нужны.

## Важно

Post-process Effect в Owlbear Rodeo помечен как экспериментальный. Если он не сработает, титр и затемнение через полноэкранный overlay всё равно останутся рабочими.
