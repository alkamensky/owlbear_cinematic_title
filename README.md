# Cinematic Location Titles

Кинематографичные заставки названий локаций для **Owlbear Rodeo**.

GM выбирает тему, вводит название локации и показывает титр всем игрокам одновременно. Последняя выбранная тема запоминается и не сбрасывается при переходе между сценами.

## Установка

В Owlbear Rodeo открой:

**Extensions → Add Extension**

И вставь Manifest URL:

```text
https://cinematic-title.altraboxel.workers.dev/manifest.json
```

## Темы

### MÖRK BORG

- сильное затемнение и контраст сцены;
- монохромная стилистика;
- падающие черепа;
- чёрно-белый титр с красными кровавыми акцентами;
- резкое появление и лёгкий jitter.

### LANCER

- cyber-glitch перед появлением названия;
- крупная рука меха проходит через экран;
- текст раскрывается в процессе движения;
- отдельные шрифты для латиницы и кириллицы;
- красные, cyan и magenta glitch-акценты.

### D&D

- классическая таверная стилистика;
- деревянная вывеска падает сверху;
- небольшой отскок и затухающие рывки;
- тёплый fantasy-шрифт.

### WARHAMMER

- тяжёлая готическая металлическая конструкция;
- элементы рамки собираются по частям;
- буквы названия «вбиваются» в центральную пластину;
- искры и короткие удары при сборке;
- не поддерживается `Ё` (автоматически меняется на `Е`).

## Возможности

- четыре готовые темы без ручной настройки дизайна;
- показ заставки сразу всем игрокам;
- заголовок и необязательный подзаголовок;
- выбор длительности показа;
- настройка степени затемнения сцены;
- попытка автоматически подставить название текущей сцены или основной карты;
- ручная кнопка **СКРЫТЬ**;
- управление доступно только GM.

## Использование

1. Открой панель **Cinematic Title**.
2. Выбери тему.
3. Введи название локации или оставь автоматически найденное.
4. При необходимости добавь вторую строку.
5. Выбери длительность и степень затемнения.
6. Нажми **ПОКАЗАТЬ ВСЕМ**.

Чтобы убрать заставку раньше времени, нажми **СКРЫТЬ**.
