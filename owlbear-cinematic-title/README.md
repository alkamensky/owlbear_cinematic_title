# Cinematic Title — Owlbear Rodeo Extension

Аддон для **Owlbear Rodeo**, который позволяет GM показывать всем игрокам кинематографичные названия локаций.

## Темы v3

- **MÖRK BORG** — карта уходит в высокий контраст; на фоне идёт дождь из черепов, а в центре резко появляется грязный ч/б титр с красными кровавыми акцентами.
- **LANCER** — короткий cyber-glitch, затем механическая рука прорезает экран и раскрывает название.
- **D&D** — тяжёлая таверная вывеска падает сверху, вздрагивает и слегка раскачивается.
- **WARHAMMER** — металлическая готическая конструкция собирается по частям, после чего буквы быстро «вбиваются» в центральную пластину.

Последняя выбранная тема сохраняется в браузере GM и не сбрасывается при смене сцены.

## Установка

В Owlbear Rodeo: **Extensions → Add Extension**

```text
https://cinematic-title.altraboxel.workers.dev/manifest.json
```

## Шрифты

Нужные шрифты уже вложены в папку `fonts/` внутри архива.

- **MÖRK BORG** — `FF_troublemarker.otf`
- **LANCER** — `SDDystopianDemo` для латиницы и `CyberSiberia` для кириллицы
- **D&D** — `Alegreya-Black.ttf`
- **WARHAMMER** — `engo.ttf`

В WARHAMMER буква `Ё` автоматически заменяется на `Е`.

## Развёртывание

Аддон полностью статический. Node.js и сборка не нужны. Загрузите содержимое папки на Cloudflare/статический хостинг.
